# Tile links

Staff can paste a tile link into WhatsApp or email. The link names the topic only.
It never includes a Student ID, a date of birth, a name, or a personal token.

Format: `?tile=<slug>`

Example: `?tile=travel-signature`

If the student is not logged in, the page asks for Student ID and date of birth, then opens that tile. An unknown slug opens the menu.

Each tile has a **Copy link to this tile** button. The copied address is the page plus `?tile=` and nothing else.
